# План проекта: сайт земельных участков

> Одностраничный информационный сайт по образцу [zemlion.ru](https://zemlion.ru/) и [zaozerie.org](https://zaozerie.org/).  
> Несколько участков, минимальный бэкенд, контент редактируется в файлах.

---

## 1. Цель проекта

Создать быстрый, понятный сайт для презентации одного или нескольких земельных участков (или посёлка с участками). Посетитель должен:

- увидеть ключевые преимущества локации;
- просмотреть список участков с фильтрацией;
- открыть карточку участка с деталями;
- оставить заявку на просмотр / звонок;
- найти контакты и схему проезда.

Сайт **не является публичной офертой** — только информационный каталог.

---

## 2. Выбор технологий

| Слой | Решение | Почему |
|------|---------|--------|
| Фреймворк | **Astro 5** (SSG) | Статическая генерация, быстрая загрузка, минимум JS на клиенте |
| Язык | **TypeScript** | Типизация данных участков, меньше ошибок при добавлении контента |
| Контент | **Markdown + YAML frontmatter** | Участки как файлы в `src/content/plots/` — без CMS и БД |
| Стили | **CSS / Tailwind** (на выбор) | Простая вёрстка, легко поддерживать |
| Карта | **Leaflet + OpenStreetMap** или **Яндекс.Карты** | Показ участков на карте без своего бэкенда |
| Форма заявки | **Formspree / Telegram Bot API / EmailJS** | Отправка без сервера |
| Аналитика | **Яндекс.Метрика** | Стандарт для RU-аудитории |
| Хостинг | **Vercel / Netlify / GitHub Pages** | Бесплатный деплой статики из git |

**Почему не WordPress / 1C-Bitrix:** избыточно для 5–50 участков без админки.  
**Почему не React SPA:** лишний JS, хуже SEO без SSR.  
**Почему не полноценный бэкенд:** участки меняются редко, достаточно git + redeploy.

## 3. Структура сайта (одна страница + детальные)

### Главная (лендинг)

1. **Шапка** — логотип, телефон, кнопка «Оставить заявку», навигация по якорям.
2. **Hero-блок** — заголовок, УТП, фон (фото местности), CTA.
3. **Ключевые преимущества** — иконки + короткие тезисы (расстояние до города, коммуникации, природа, документы).
4. **О локации / о проекте** — текст + фото/видео.
5. **Каталог участков** — карточки с фильтром (район, статус, площадь, цена).
6. **Карта** — все участки на одной карте с маркерами.
7. **Инфраструктура рядом** — магазины, озеро, дороги, школа и т.д.
8. **Документы** — ссылки на PDF (выписки, проект, разрешения).
9. **FAQ** — частые вопросы (прописка, категория земли, рассрочка).
10. **Контакты** — телефоны, email, адрес офиса, режим работы, форма.
11. **Подвал** — дисклеймер оферты, копирайт, политика конфиденциальности.

### Страница участка (опционально, `/plots/[slug]`)

Отдельная страница для SEO и шаринга в мессенджерах.

## 4. Модель данных одного участка

Каждый участок — файл `src/content/plots/<slug>.md` с frontmatter:

```yaml
---
id: "001"                          # Внутренний номер (как [277] на zemlion.ru)
title: "Участок у озера Шейно"     # Название для карточки
status: available                  # available | reserved | sold
# URL формируется из имени файла: uchastok-u-ozera-sheino.md → /plots/uchastok-u-ozera-sheino
region: "Тверская область"
district: "Калининский район"      # Район (для фильтра)
settlement: "д. Заозерье"          # Населённый пункт
areaHa: 0.12                       # Площадь в гектарах
areaSotka: 12                      # Площадь в сотках (опционально, можно считать)
landCategory: izhs                 # izhs | agricultural | other
priceRub: 450000                   # Цена, ₽ (или «по запросу»)
pricePerSotkaRub: 37500            # Цена за сотку
cadastralNumber: "69:11:0070123:45"
coordinates:
  lat: 56.8234
  lng: 35.9012
communications:
  electricity: true
  gas: true
  water: true
  sewer: false
  road: "асфальт / грунтовая"
distance:
  toCityKm: 25                     # До Твери
  toHighwayKm: 3
  toLakeKm: 0.5
features:
  - "Вид на озеро"
  - "Ровный рельеф"
  - "Лесной массив рядом"
gallery:
  - "/images/plots/001/photo-1.jpg"
  - "/images/plots/001/photo-2.jpg"
documents:
  - "/docs/plots/001/vypiska.pdf"
published: true
sortOrder: 1
---

## Описание участка

Свободный Markdown-текст: рельеф, подъезд, что рядом, условия сделки, что входит в стоимость.
```

## 5. Какие данные нужно собрать перед запуском

### По каждому участку

- [ ] Название / номер лота
- [ ] Точный адрес или привязка к населённому пункту
- [ ] Площадь (га и/или сотки)
- [ ] Категория земли (ИЖС, с/х и т.д.)
- [ ] Кадастровый номер
- [ ] Координаты (GPS или с карты)
- [ ] Цена и условия (рассрочка, что входит)
- [ ] Статус (в продаже / бронь / продан)
- [ ] Коммуникации (электричество, газ, вода, дорога)
- [ ] Расстояния (до города, МКАД, озера, магазина)
- [ ] 5–15 фото (лето/зима, подъезд, вид)
- [ ] Описание текстом (300–800 слов)
- [ ] Документы (выписка ЕГРН, по желанию)

### По проекту в целом

- [ ] Название бренда / посёлка
- [ ] Логотип
- [ ] Контакты и режим работы
- [ ] Текст «О нас» / «О локации»
- [ ] Видео (YouTube/VK embed)
- [ ] Схема проезда (скрин с карт или PDF)
- [ ] Юридический дисклеймер
- [ ] Политика обработки персональных данных (152-ФЗ)

## 8. Как добавить новый участок

1. Положить фото в `public/images/plots/<id>/`.
2. Создать `src/content/plots/<slug>.md` по шаблону выше.
3. Запустить `npm run build` — Astro проверит схему.
4. Закоммитить и задеплоить — участок появится на сайте.

Без админки, без базы данных. Для 5–30 участков — оптимально.
